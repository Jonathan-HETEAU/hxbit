interface NetworkSerializable

package hxbit

extends ProxyHost, Serializable

@:directlyUsed@:build(hxbit.Macros.buildSerializable())@:autoBuild(hxbit.Macros.buildSerializable())@:autoBuild(hxbit.Macros.buildNetworkSerializable())

Available on all platforms

A Serializable object that can be replicated over the network by a NetworkHost: its @:s fields are synchronized from the authority to the clients, and its @:rpc methods are remote procedure calls (see the README for the RPC modes and the @:increment, @:condSend, @:notMutable, @:noSync, @:noSave and @:visible field metadata).

The macro generates the fields of this interface, a networkProp<Name> constant for each field (see networkCancelProperty) and networkLocalChange(f), which runs f without sending the changes. Set enableReplication to share the object: alive is then called on the clients when it is received.

Variables

__bits1:Int

The changed properties 0 to 29, as bits.

__bits2:Int

The changed properties 30 and above, as bits.

__dirtyVisibilityGroups:Int

Available on hxbit_visibility

The visibility groups to evaluate again, as bits.

__host:NetworkHost

The host replicating the object, or null.

__next:NetworkSerializable

The next object of the list of changed objects of the host (or the object itself when enableAutoReplication is set).

__visibilityCount:Int

Available on hxbit_visibility

The number of clients the object was sent to, minus one.

enableAutoReplication:Bool

Shares the object automatically when it is first sent over the network (as a value of a replicated object).

enableReplication:Bool

Shares the object with the current NetworkHost when set, and stops sharing it when unset.

Methods

alive():Void

Called on the clients when the object has been received and fully initialized, and by NetworkHost.makeAlive after loading a state. Sets enableReplication by default: define it to do your initialization.

evalVisibility(group:VisibilityGroup, from:NetworkSerializable):Bool

Available on hxbit_visibility

Tells if the properties of the visibility group are visible to the client (the owner object of a NetworkClient). Returns false by default.

getNoSaveMask():Int64

Returns the @:noSave properties, as bits. Generated by the macro.

getRPCSchema():Schema

Returns the schema of the RPCs. Generated by the macro.

getVisibilityMask(groups:Int):Int64

Available on hxbit_visibility

Returns the properties visible with the visibility groups groups, as bits. Generated by the macro.

networkAllow(op:Operation, propId:Int, client:NetworkSerializable):Bool

Tells if the client (the owner object of a NetworkClient) is allowed to do the operation, on the property or RPC propId. Returns false by default: define it to give rights to the clients.

networkFlush(ctx:Serializer):Void

Writes the changed properties and clears their bits. Generated by the macro.

@:value({ isRPC : false })networkGetName(propId:Int, isRPC:Bool = false):String

Returns the name of a property, or of a RPC if isRPC is set. Generated by the macro.

networkRPC(ctx:NetworkSerializer, rpcID:Int, clientResult:NetworkClient):Bool

Reads the arguments of the RPC rpcID and executes it. Generated by the macro.

networkSetBit(bit:Int):Void

Marks the property bit as changed, to be sent at the next NetworkHost.flush. Generated by the macro.

networkSync(ctx:Serializer):Void

Reads the changed properties. Generated by the macro.

setVisibilityDirty(group:VisibilityGroup):Void

Available on hxbit_visibility

Requests a new evaluation of the visibility group, for example when the result of evalVisibility changed. Generated by the macro.
