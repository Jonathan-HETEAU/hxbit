HxBit API

hxbit

..
AnySerializable

A value serialized by a Serializer: a Serializable object, or a StructSerializable structure.

ArrayProxy

The proxy of an Array stored in a property of a NetworkSerializable: the functions modifying the array mark the property as changed, which sends the whole array again. Arrays are converted to proxies implicitly.

ArrayProxy2

The proxy of an Array of proxies (an array of mutable values): like ArrayProxy, and the values are bound to the array, so that their changes mark the property as changed.

ArrayProxyData

The data of an ArrayProxy: the wrapped array, and the property of the host it is bound to.

ArrayProxyIterator

An iterator over the values of an array.

BaseProxy

The base class of the generated proxies.

Closure

A serializable function, returning T: create it with Closure.make(function() ...). The code is compiled in a generated class (in the hxbit.closure package) and the captured local variables are serialized with the closure, so it can be stored or sent and called later.

Convert

The conversion of the data of a class saved with an older schema: removed fields are skipped, added fields get a default value, and fields whose type changed are converted (see registerConverter). The values of the removed fields are stored in the oldHxBitFields field of the object, if it has one.

ConvertField

How a field is converted from the saved schema to the current one.

CustomSerializable

Custom serializable are more lightweight (no versioning etc.) than normal Serializable but a bit larger when serializing. They don't have any extra data field added such as uid, and should be only referenced once

Double

A Float that is serialized with full 64 bits precision (instead of 32 bits for Float).

Dump

Converts versioned data (written by Serializer.endSave) to a structure that can be saved as JSON, for debugging. The classes are not needed: the schemas stored in the data are used. Only on sys targets.

EnumFlagsData

The data of an EnumFlagsProxy: the wrapped flags, and the property of the host it is bound to.

EnumFlagsProxy

The proxy of haxe.EnumFlags stored in a property of a NetworkSerializable: setting or unsetting a flag marks the property as changed.

FieldType

The type of a serialized field, as stored in a Schema.

Macros

The macros generating the serialization and network code of Serializable, StructSerializable and NetworkSerializable classes, and helpers called by the generated code.

MapData

The data of a MapProxy: the wrapped map, and the property of the host it is bound to.

MapProxy

The proxy of a Map stored in a property of a NetworkSerializable: the functions modifying the map mark the property as changed, which sends the whole map again. Maps are converted to proxies implicitly.

MapProxy2

The proxy of a Map of proxies (a map of mutable values): like MapProxy, and the values are bound to the map, so that their changes mark the property as changed.

MarkInfo

The marking parameters of AnySerializable.markReferences: set is the bits set on the marked objects (__mark), mask the bits kept.

MarkParam

The visibility groups of the objects, by UID, used when marking the references visible from a client (null for all the references).

NetworkClient

A connection of a NetworkHost: on the server (authority), one for each connected client; on a client, the connection to the server. Extend it to send the data (override send) and call processMessagesData when data is received.

NetworkHost

Replicates NetworkSerializable objects between a server (the authority, isAuth) and its clients: sends the changed properties, the registered and unregistered objects and the RPCs.

NetworkNoReplication

Classes implementing this will not be replicated over the network

NetworkProperty
NetworkSerializable

A Serializable object that can be replicated over the network by a NetworkHost: its @:s fields are synchronized from the authority to the clients, and its @:rpc methods are remote procedure calls (see the README for the RPC modes and the @:increment, @:condSend, @:notMutable, @:noSync, @:noSave and @:visible field metadata).

NetworkSerializer

The Serializer of a NetworkHost and of its clients: it writes the @:noSave fields (forSave is false), shares the objects with enableAutoReplication when they are sent, and checks that the referenced objects are known.

NetworkStats

Collects the number of times each property and RPC is sent and the number of bytes used, by class (see NetworkHost.setStats).

Operation

The operations a client can be allowed to do on an object, checked with NetworkSerializable.networkAllow.

PropType

A serialized type, with the options given by the field metadata.

PropTypeDesc

The type of a serialized value, as used by the macros and stored in the schemas (see Schema.FieldType).

Proxy

The proxy type generated for the mutable type T (Array, Map, haxe.ds.Vector, structure): wraps a value to mark the network property changed when the value is modified (see ArrayProxy, MapProxy, VectorProxy).

ProxyChild

A proxy, wrapping a mutable value stored in a property of a ProxyHost.

ProxyHost

An object notified when a value it contains is modified: a NetworkSerializable, or a proxy containing other proxies.

ReadOnly

The read-only version of the type T, generated by a macro: arrays, maps, vectors and structures are replaced by read-only types, recursively.

ReadOnlyArray

A read-only array.

ReadOnlyMap

A read-only Map.

ReadOnlyVector

A read-only haxe.ds.Vector.

RpcMode

The modes of the @:rpc(mode) methods of a NetworkSerializable.

Schema

The description of the serialized fields of a class, an enum or a structure: stored with the data by Serializer.endSave, and compared with the current schema by Serializer.beginLoad to convert data saved with older versions.

Serializable

An object serialized by a Serializer: its fields marked with @:s are serialized, by code generated at compile time (hxbit.Macros.buildSerializable). The fields of this interface are generated by the macro.

SerializableEnum

The serializer generated for the enum T (in the hxbit.enumSer package), with static methods to serialize, unserialize and get the schema of its values.

Serializer

Reads and writes the binary data of Serializable objects and of the basic values.

Stat

The statistics of a property or of a RPC.

StatClass

The statistics of a class.

StructSerializable

StructSerializable is a slighlty more compact version of Serializable, but doesn't have a unique id so it shouldn't be referenced multiple times. This allows for small objects created on-the-fly that will not need to be cleaned from the references cache. Its data Schema will be included in all the objects that reference it similar to a normal anonymous structure { ... }

TypeConvert

The conversion of the values of an enum or a structure saved with an older schema.

UID

The unique identifier of a Serializable object: an Int, or an haxe.Int64 with -D hxbit64. The highest bits store the sequence number (see NetworkHost).

UIDMap

A map of values by object UID.

VectorProxy

The proxy of a haxe.ds.Vector stored in a property of a NetworkSerializable: setting a value or sorting marks the property as changed, which sends the whole vector again. Vectors are converted to proxies implicitly.

VectorProxyData

The data of a VectorProxy: the wrapped vector, and the property of the host it is bound to.

VisibilityGroup

The visibility groups of the @:visible(group) fields, set with hxbit.Macros.initVisibility (with -D hxbit_visibility).

VisibilityGroupDef

The visibility groups set with hxbit.Macros.initVisibility. Generated by hxbit.Macros.

Weak

A weak reference to a NetworkSerializable object: stores its UID only, and resolves it from the current NetworkHost.
